# Decision log entry template

Append one entry per recorded decision to `docs/decisions.md`.
If the file does not exist, create it with a `# Decisions` heading first.

```markdown
### <YYYY-MM-DD> — <Topic>
**Decision:** <chosen option, or the user's custom answer>
**Options considered:** <A>; <B>; <C>
**Why:** <one or two lines taken from the discussion>
**Affects:** <files / components / later decisions>
```
